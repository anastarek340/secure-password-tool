# 🔐 Password Strength Checker

A simple and modern web tool that checks password strength in real-time.

---

## 🚀 Features
- Live password strength meter
- Security score system
- Suggestions to improve password
- Password generator
- Copy to clipboard
- Show/Hide password

---

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 🎯 How it works
The tool evaluates password strength based on:
- Length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Common password detection
